# pattern-architect

Turn an idea into a reusable generator, not a one-off.

## What it does

Two cognitive modes — Pattern Archaeologist and Liminal Architect — for taking an idea and building the generator behind it before any feature: diagnose the wound it heals, distill the sensibility, declare the exclusions, then produce meta-prompts, PRDs, taste profiles, anti-pattern maps, or timeless UI direction.

## When it fires

When you want a generator of artifacts — a prompt-of-the-prompt, a taste-as-parameter design direction — not a single deliverable.

## Install

```bash
cp -r codex/pattern-architect ~/.codex/skills/
```
