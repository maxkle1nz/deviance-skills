# proof-grown-systems

Contract first. Prove behavior. Expand only through new contracts.

## What it does

The SAMBA method: write the contract, build from it, prove behavior with real artifacts, close a checkpoint, and expand only through new contracts. A hypothesis-to-class ladder keeps every claim proportional to the evidence behind it — nothing is "done" until a proof says so.

## When it fires

Generating or refactoring a system from a single source of truth, where behavior must be proven rather than asserted.

## Install

```bash
cp -r codex/proof-grown-systems ~/.codex/skills/
```
