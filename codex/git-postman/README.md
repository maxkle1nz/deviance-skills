# git-postman

Git with a reputation to protect.

## What it does

A guard for anything public — commits, PR titles, release notes, README and landing copy. It enforces maintainer voice over assistant voice, checks that project communication reads as credible to real developers, and sits behind a secrets, identity, and force-push safety gate. It ships a commit-message linter.

## When it fires

Before any commit, push, publish, or history rewrite; whenever public repo copy needs to sound like a person wrote it.

## Install

```bash
cp -r codex/git-postman ~/.codex/skills/
```
