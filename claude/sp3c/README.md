# sp3c

One spec agents build from — the KERNEL-SPEC pattern.

## What it does

The single executor-normative specification that lets agent executors implement a BIG system from the document alone, without the author in the loop. Every rule is numbered and testable; vague words are defects; silence becomes a seat-request instead of a guess; and amendments consolidate before they rot into two competing specs. Battle-proven: one real KERNEL-SPEC governed nine waves of executors with zero semantic improvisation.

## When it fires

Before opening any lab where executors build from a document alone, or when a spec's amendments are piling up. Not for living state (pathos), runbooks (m4nual), or product PRDs.

## Install

```bash
cp -r claude/sp3c ~/.claude/skills/
```

The skill body is written in Portuguese.
