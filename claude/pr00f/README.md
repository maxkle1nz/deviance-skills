# pr00f

Prove first, design after.

## What it does

For a new feature where the answer isn't known yet. Phase P opens an isolated lab — its own worktree, runtime, and fixture — with a contract battery that is RED before any code exists; you spike it to GREEN without touching the asserts, then push it through an adversarial and property harness up to a real oracle: a compiler, a self-host, something that can't be argued with. Phase D distills the PRD from what the spike actually proved, with a proof-address on every claim.

## When it fires

For exploratory features that have a cheap, objective oracle. Not for CRUD, and never a substitute for the compiler.

cp -r claude/pr00f ~/.claude/skills/
