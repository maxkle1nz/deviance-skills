# v1tals

A periodic health checkup that ends in fixes, not a report.

## What it does

Sweeps a repo across technical debt, real browser e2e, design taste against a high bar, ergonomics — the five states of every screen — animation, and performance. The difference from a linter: it dispatches the fixes it finds instead of filing them in a drawer.

## When it fires

Every few merges, before a gate, or as a fortnightly backstop. Not a replacement for unit tests.

## Install

```bash
cp -r claude/v1tals ~/.claude/skills/
```

The skill body is written in Portuguese.
